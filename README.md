# بلند بگو — Out Loud

اتاق تمرین مکالمه‌ی انگلیسی برای بزرگسالان. بلند حرف بزن، بعدش بفهم بهتر چطور می‌شد گفت — بدون اینکه وسط حرفت کسی بپرد.

## چرا این‌طوری ساخته شد

قویترین پیش‌بینی‌کننده‌ی روان‌شدن در یک زبان، «زمان صحبت‌کردن» است — نه دستور زبان،
نه واژه. برای همین:

- هر سناریو یک **هدف** دارد و طرف مقابل یک **دستور کار پنهان** — اصطکاک واقعی، نه فقط گپ.
- طرف مقابل **هرگز** وسط مکالمه تصحیح نمی‌کند و از نقشش بیرون نمی‌آید.
- تصحیح **فوری** ولی **بی‌صدا** است: در ریل فارسی کنار صفحه ظاهر می‌شود، نه در دهان طرف مقابل.
- نوار پایین صفحه نشان می‌دهد چند درصد مکالمه را واقعاً **تو** گفتی.
- در پایان، عبارت‌های یادگرفته‌شده با سیستم Leitner در «بانک عبارات» ذخیره می‌شوند
  و در جلسه‌ی بعد برای مرور برمی‌گردند.

## راه‌اندازی

```bash
npm install
npm run setup:fonts   # یک‌بار — فونت‌های لاتین را دانلود می‌کند
cp .env.example .env
npm start
```

سرور روی `http://localhost:5173` بالا می‌آید. **همین الان، بدون هیچ کلید API،
کاملاً کار می‌کند** — موتور پیش‌فرض `mock` است: مکالمه‌ها از پیش نوشته شده‌اند،
تصحیح‌ها قانون‌محورند (خطاهای رایج فارسی‌زبان‌ها مثل «I am agree»)، و جمع‌بندی
از خودِ متن گفت‌وگو محاسبه می‌شود.

## وقتی کلید API گرفتی

۱. یک کلید از [console.anthropic.com](https://console.anthropic.com) بگیر.
۲. در فایل `.env`:
   ```
   ENGINE=claude
   ANTHROPIC_API_KEY=sk-ant-...
   ```
۳. سرور را دوباره اجرا کن. همان اپ، همان رابط کاربری — این بار طرف مقابل واقعاً
   با Claude Opus 5 جواب می‌دهد، تصحیح‌ها هوشمندتر می‌شوند، و جمع‌بندی از تحلیل
   واقعی مکالمه می‌آید.

هیچ کد دیگری لازم نیست عوض شود — موتور mock و موتور claude پشت یک اینترفیس
یکسان‌اند (`server/engine/index.mjs`).

## ساختار پروژه

```
content/scenarios.json     ۱۲ سناریوی هدف‌دار (۶ کاری + ۶ روزمره)
content/topics.json        ۱۲ موضوع گفت‌وگوی آزاد
server/index.mjs           سرور node:http — بدون فریم‌ورک
server/engine/mock.mjs     موتور آفلاین — بدون کلید کار می‌کند
server/engine/claude.mjs   موتور واقعی — با Claude Opus 5
server/prompts/            پرامپت‌های سیستمی هر سه بخش (طرف مقابل / مربی / جمع‌بندی)
public/                    رابط کاربری — بدون فریم‌ورک، بدون build step
public/lib/store.mjs       بانک عبارات با سیستم Leitner (localStorage)
public/lib/speech.mjs      تشخیص گفتار و خواندن متن، بومی مرورگر
public/lib/ribbon.mjs      نوار گفت‌وگو
```

## نکات فنی

- بدون فریم‌ورک، بدون بسته‌بندی (bundler) — فایل‌های `.mjs` مستقیم در مرورگر و Node اجرا می‌شوند.
- تشخیص گفتار روی Chrome/Edge کار می‌کند (Web Speech API). در مرورگرهای دیگر،
  خودکار به ورودی متنی برمی‌گردد — هیچ قابلیتی از دست نمی‌رود.
- هیچ حساب کاربری، هیچ دیتابیس — همه‌چیز در `localStorage` همان مرورگر می‌ماند.
- کلید API فقط سمت سرور خوانده می‌شود؛ هرگز به مرورگر نمی‌رسد.
